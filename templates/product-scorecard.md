## Red flag checklist

Pause or simplify the idea if several of these are true:

- [ ] The function is hard to explain visually.
- [ ] It needs many test prints before knowing if it works.
- [ ] It depends on tight screw threads or precise friction fits.
- [ ] It has thin fragile parts.
- [ ] It is easy for anyone to copy without a unique angle.
- [ ] It would take more than one week before a useful prototype.
- [ ] It does not solve a clear problem.
- [ ] It only feels interesting because it is technically complicated.
