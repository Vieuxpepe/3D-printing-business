# Release Checklist

Use this checklist before publishing a model.

## Model quality

- [ ] Model is complete.
- [ ] Scale is correct.
- [ ] Mesh is clean.
- [ ] No accidental floating parts.
- [ ] No unnecessary tiny fragile details.
- [ ] File names are clear.

## Print testing

- [ ] Test print completed.
- [ ] Important tolerances tested.
- [ ] Supports tested or support-free confirmed.
- [ ] Weak points checked.
- [ ] Assembly tested if applicable.
- [ ] Photos taken after print.

## User experience

- [ ] Product function is clear from thumbnail.
- [ ] Instructions are easy to understand.
- [ ] Required hardware is listed.
- [ ] Assembly steps are explained.
- [ ] Common mistakes are mentioned.

## Marketplace listing

- [ ] Strong title.
- [ ] Clear short description.
- [ ] Good keywords.
- [ ] Print settings included.
- [ ] License selected.
- [ ] Images/renders uploaded.
- [ ] Files organized.

## Post-release

- [ ] Check comments after release.
- [ ] Track complaints in `feedback/customer-feedback.md`.
- [ ] Add improvement ideas to the product page.
- [ ] Decide if a version 2 is needed.
