# Market Research and Product Analysis

This folder stores market observations, product analysis, competitor notes, marketplace trends, and lessons learned from the 3D printing market.

Use this folder when the user notices something about:

- what sells well
- what does not sell well
- customer complaints
- product categories with potential
- MakerWorld trends
- Cults3D trends
- pricing patterns
- thumbnail and listing quality
- printability expectations
- common tags and keywords
- product opportunities

## Main files

| File | Purpose |
|---|---|
| `market-observations.md` | Running notes about trends, demand, and marketplace behavior |
| `product-analysis-log.md` | Structured analysis of specific product ideas or existing models |
| `competitor-observations.md` | Notes about competing products, without copying protected designs |
| `opportunity-map.md` | Promising categories and product gaps to explore |

## How to use this folder

When the user mentions a market observation, add it to the most relevant file.

Examples:

- If the user says knights sell well, add it to `market-observations.md`.
- If the user wants to compare product ideas, use `product-analysis-log.md`.
- If the user notices a competitor pattern, use `competitor-observations.md`.
- If the user finds a possible product category, use `opportunity-map.md`.

## Important rules

- Do not copy competitors directly.
- Focus on patterns, opportunities, and lessons.
- Separate evidence from assumptions.
- Mark uncertain observations clearly.
- Link product insights back to `product-catalog/` when relevant.

## Observation format

Use this simple structure:

```text
Date:
Observation:
Source:
Confidence: Low / Medium / High
Why it matters:
Possible action:
Related product file:
```

## Goal

The goal is to help the user make better product decisions instead of relying only on gut feeling.
