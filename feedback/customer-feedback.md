# Customer Feedback

Use this file to track feedback, complaints, requests, and improvement ideas from customers.

## Feedback categories

- **Print issue**: tolerance, supports, failed print, weak part
- **Assembly issue**: screw, fit, clip, moving part
- **Description issue**: unclear listing or instructions
- **Feature request**: customer wants an extra version or option
- **Positive feedback**: what people liked

## Known feedback

### Screw mechanism complaint on previous model

**Category:** Assembly issue  
**Product:** Previous organizer/accessory model  
**Feedback:** Some people complained that the screw did not work, even though it worked on my printer.

Possible causes:

- tolerances too tight
- printer calibration differences
- thread design too sensitive
- not enough clearance
- unclear instructions

Lessons:

- avoid screw mechanisms when not necessary
- use looser tolerances for public models
- include test pieces if tolerances matter
- write clear print and assembly instructions
- design for imperfect printers, not only my own printer

## Improvement principles

- Repeated complaints matter more than one-off complaints.
- Assembly complaints should be taken seriously.
- If a model depends on tight tolerances, include a test piece.
- Clear instructions can reduce support messages.
- A simpler mechanism is often better for public release.
