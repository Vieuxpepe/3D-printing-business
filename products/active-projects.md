# Active Projects

This file tracks projects that are actually being worked on or seriously considered.

For polished product records, marketplace descriptions, MakerWorld tags, version history, and release-ready information, use:

```text
product-catalog/
```

The `products/` folder is for active working notes. The `product-catalog/` folder is the long-term product memory.

## Project status labels

- **Idea**: rough concept
- **Scoring**: being evaluated with the product scorecard
- **Planning**: being defined
- **Prototype**: being modeled or test printed
- **Test Print**: print and usability checks
- **Fixes**: improving weak points or tolerances
- **Listing Prep**: renders, photos, description, files
- **Released**: published
- **Version 2**: improvement based on feedback
- **Paused**: stopped for now
