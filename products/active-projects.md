# Active Projects

This file tracks projects that are actually being worked on or seriously considered.

## Project status labels

- **Idea**: rough concept
- **Planning**: being defined
- **Prototype**: being modeled or test printed
- **Testing**: print and usability checks
- **Listing prep**: renders, photos, description, files
- **Released**: published
- **Paused**: stopped for now
