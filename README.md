# 3D Printing Business — Planning Hub

A simple, Markdown-based planning hub for managing a 3D printing business.  
Everything lives in plain `.md` files — no apps, no dependencies.

---

## 📂 Folder Structure

| Folder | Purpose |
|--------|---------|
| [`01-product-ideas/`](01-product-ideas/) | Capture and evaluate new product ideas |
| [`02-active-projects/`](02-active-projects/) | Track ongoing print/design projects |
| [`03-weekly-agenda/`](03-weekly-agenda/) | Plan and review each week |
| [`04-customer-feedback/`](04-customer-feedback/) | Log feedback, reviews, and requests |
| [`05-model-release-checklist/`](05-model-release-checklist/) | Checklist before publishing a model |
| [`06-product-descriptions/`](06-product-descriptions/) | Ready-to-paste descriptions for MakerWorld & Cults3D |
| [`07-future-opportunities/`](07-future-opportunities/) | Long-term ideas, markets, and opportunities |

---

## 🚀 How to Use

1. **Copy the template** (`_template.md`) inside the relevant folder.
2. **Rename the copy** to something descriptive (e.g., `2026-W18.md`, `flexi-dragon.md`).
3. **Fill in the sections** — delete anything that doesn't apply.
4. Commit or save — everything stays readable in any text editor or on GitHub.

---

## 🏷️ Priority Tags

Use these tags anywhere inside a file to make scanning easy:

- `#urgent` — needs attention today
- `#high` — important this week
- `#medium` — important this month
- `#low` — nice to have
- `#blocked` — waiting on something external
- `#done` — completed

---

## 📝 Notes

- All templates are in their folder as `_template.md` (or `_template-platform.md`).
- Dates follow `YYYY-MM-DD` or `YYYY-WXX` for weekly files.
- Keep file names lowercase with hyphens.
