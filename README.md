# 3D Printing Business Hub

This repository is a simple planning hub for my 3D printing business.

It is meant to help organize:

- product ideas
- active projects
- weekly agendas
- customer feedback
- launch checklists
- MakerWorld and Cults3D descriptions
- future opportunities

## Current focus

The current direction is to prioritize practical, printable models that are useful, visually appealing, and not overly complicated to produce.

Main product directions:

1. Miniature transport and storage organizers
2. Knight and fantasy miniature series
3. Wild animal models
4. Practical gaming accessories
5. Improved versions of previous models based on customer feedback

## How to use this repository

Use this repo as a working brain. Add rough ideas quickly, then organize them later into priorities, active projects, or paused ideas.

A simple workflow:

1. Capture ideas in `ideas/product-ideas.md`.
2. Move promising concepts into `products/active-projects.md`.
3. Plan the week in `planning/weekly-agenda.md`.
4. Track user complaints and requests in `feedback/customer-feedback.md`.
5. Use the templates before publishing a model.

## Guiding principles

- Prefer models that solve a real problem.
- Avoid designs that are too fragile or annoying to print.
- Keep support requirements low when possible.
- Make products look clean and professional.
- Use customer feedback to guide version 2 improvements.
- Avoid overcomplicating designs just because they are technically impressive.
