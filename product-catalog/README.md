# Product Catalog

This folder stores one Markdown file per 3D printing product.

Each product file should include:

- product name
- status
- short description
- full concept
- target users
- problem solved
- design notes
- print settings
- included files
- MakerWorld listing text
- 50 tags
- version history
- feedback
- next actions

## Naming convention

Use lowercase words separated by hyphens.

Examples:

```text
miniature-transport-organizer.md
temple-knight-commander.md
fantasy-wolf-companion.md
```

## Status labels

Use one of these labels:

- Idea
- Scoring
- Planning
- Prototype
- Test Print
- Fixes
- Listing Prep
- Released
- Version 2
- Paused
- Rejected
