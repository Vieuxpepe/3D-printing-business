# Goblin Warrior Miniature

## Concept

A goblin warrior miniature designed for tabletop RPGs, wargaming, and fantasy collections. Features spiked armor, dual weapons, and a menacing pose. Integrated round base included.

## Features

- Goblin warrior character
- Spiked armor details
- Dual weapons included
- Round scenic base for stability
- Good silhouette for tabletop readability
- Works at miniature scale and larger display scale

## Print Profile Notes

**Recommended material:** PLA / PETG / resin  
**Supports:** yes  
**Layer height:** 0.08 mm recommended for FDM, 0.03-0.05 mm for resin  
**Infill:** 15-20% for FDM  
**Estimated print time:** varies by scale and printer

## Assembly

- None required; prints as a single piece with integrated base.

## Tips

- Tree supports recommended around weapons and spikes
- Let FDM prints cool before removing supports
- Careful handling for small overhangs
- Print larger for easier painting and detail visibility
