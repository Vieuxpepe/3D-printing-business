# Knight Miniature Support-Removal Improvement

## Product summary

**Working product name:** Knight - Miniature  
**Category:** Fantasy miniature / tabletop miniature  
**Platform:** MakerWorld  
**Status:** Fixes  
**Priority:** High  
**Current focus:** Improve support removal and print reliability.

## Current context

The knight miniature is already a strong product signal for the business. The user is currently working on improving support removal for the knight miniature shown in the latest MakerWorld card screenshot.

This product belongs to the larger knight/fantasy miniature direction, which has been one of the user's better-performing categories.

## Current problem

The current improvement target is not the concept itself. The concept is already strong.

The key improvement target is:

> Make support removal easier and cleaner without weakening the pose, silhouette, sword, shield, or armor readability.

## Why this matters

Support removal can affect:

- user satisfaction
- public print reliability
- rating/comments on MakerWorld
- likelihood of successful prints on different machines
- chance of people saving, boosting, or remixing the model
- future trust in the knight miniature line

## Design goals

- Keep the knight silhouette strong and readable.
- Reduce difficult supports around sword, shield, legs, and underside details.
- Avoid thin floating details that snap during cleanup.
- Keep the model visually heroic from the thumbnail angle.
- Make the base and contact points support the pose where possible.
- Preserve tabletop miniature usefulness.

## Support-removal checklist

- [ ] Review overhangs around the sword and shield.
- [ ] Check if the sword tip or blade can touch the base or another solid element without looking forced.
- [ ] Check if cape, cloak, or armor edges create support traps.
- [ ] Reduce tiny underside ledges that create scarred support contact points.
- [ ] Test orientation for best detail/support balance.
- [ ] Try tree supports and standard supports if needed.
- [ ] Note the easiest Bambu Studio profile settings.
- [ ] Check if a support-free or low-support variant is possible.
- [ ] Print a test and photograph support contact areas before and after removal.

## Potential improvements

### Pose and contact points

If the sword or shield creates annoying supports, consider small sculptural contact helpers:

- sword tip lightly touching the base
- shield edge closer to body or base
- small rock/debris contact under a risky overhang
- thicker ankles or stronger foot/base connection

### Base improvements

The base can be used to hide or support structural changes.

Possible base changes:

- slightly raised terrain under sword/shield
- small stones near feet
- stronger foot contact patches
- small scenic support that looks intentional

### Print profile improvements

Potential MakerWorld print profile notes:

- recommended layer height
- recommended support type
- recommended support interface settings
- orientation screenshot if useful
- note about removing supports slowly around sword/shield

## MakerWorld listing update notes

If the support-removal improvement becomes a new version, update the listing with wording like:

> Updated version with cleaner support removal and improved print reliability around the sword, shield, and base contact areas.

Do not overpromise support-free printing unless it has been tested.
